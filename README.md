# 🛒 CommerceHub

CommerceHub is a full-stack e-commerce web application developed as a college project.

It provides a complete online shopping experience with user authentication, product browsing, shopping cart, wishlist, checkout, order management, and an admin dashboard.

## 🚀 Features

### 👤 User Features

- User Registration
- User Login
- Product Browsing
- Product Details
- Search Products
- Wishlist
- Shopping Cart
- Checkout
- Order Placement
- Order Management

### 🔐 Admin Features

- Admin Login
- Admin Dashboard
- Product Management
- Add Products
- Update Products
- Delete Products
- User Management
- Order Management

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- SweetAlert2

### Backend

- Node.js
- Express.js
- REST API

### Database

- MySQL

### Development Tools

- Visual Studio Code
- Git
- GitHub
